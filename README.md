# Elite Billiards Emporium

Build a premium modern e-commerce website for a billiards company called "B Trader Elite Billiards".

Design style:

- Inspired by https://www.atomiq.rw/

- Minimalist, elegant, luxury feel

- Color palette: Black (#000000), Gold (#C9A24A), White (#FFFFFF)

- Smooth animations, clean layout, modern typography

- Focus on high-quality visuals and product showcase

Website must include the following pages:

1. Home Page:

- Hero section with bold headline and CTA (Shop Now / Contact Us)

- Featured products section

- Services overview

- Why choose us section

- Featured projects (Hotels, Bars, Clubs)

- Testimonials preview

- WhatsApp floating button

- Promotional banner (special offers)

2. About Us:

- Company story in Kinyarwanda (Amateka ya B Trader Elite Billiards)

- Mission: Provide high-quality billiards tables and accessories

- Professional and trustworthy tone

3. Shop Page (E-commerce):

- Product categories:

  Pool Tables, Snooker Tables, Carom Tables, Cues, Cue Cases, Balls, Chalk, Triangle Racks, Table Covers, Lighting, Spare Parts

- Product filtering and search

- Product cards with image, price, rating

- Product detail page with:

  - Images

  - Description

  - Price

  - Add to cart

  - Reviews

4. Services Page:

- Billiards table installation

- Table moving

- Table repair

- Cloth replacement

- Maintenance

- Each service should have description and CTA (Book Service / WhatsApp)

5. Gallery:

- Grid layout with images and videos

- High-quality visuals

6. Projects:

- Categories: Hotels, Bars, Clubs, Homes, Schools

- Show completed installations with images

7. Testimonials:

- Customer reviews

- Images of happy clients

8. FAQ:

- Prices

- Delivery

- Warranty

- Installation

- Payment methods

9. Contact Page:

- WhatsApp click-to-chat

- Phone number

- Email

- Google Maps embed

- Contact form

10. Footer:

- Privacy Policy

- Terms & Conditions

- Warranty Policy

- Returns Policy

- Copyright © 2026 B Trader Elite Billiards

Core Features to implement:

- Full e-commerce functionality (cart, checkout)

- Customer accounts (login/register)

- Wishlist system

- Secure online payments (integrate Stripe or Flutterwave)

- Delivery tracking system

- Product reviews and ratings

- Discount and promo codes

- WhatsApp integration across all pages

- Multi-language support (English and Kinyarwanda)

- Mobile responsive design

- Fast loading and SEO optimized

Technical requirements:

- Clean database structure for products and users

- Admin dashboard for managing products, orders, users

- SEO-friendly URLs

- Optimized images

- Scalable architecture

Tone:

- Premium

- Professional

- Luxury brand feeling

- Trustworthy

Goal:

- Drive online sales

- Generate leads via WhatsApp

- Position the brand as the top billiards supplier in Rwanda
